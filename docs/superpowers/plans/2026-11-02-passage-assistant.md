# 正文选段与段落助手

**Goal:** 已写正文及草稿正文可直接选段，附带准确章节/稿件及前后文，原文旁讨论、润色或拟写替代段落；保留通用AI侧栏。
**Architecture:** SelectableProse映射DOM选区到原稿偏移；PassageAssistant放在章节辅助区。独立只读模型端点，服务端校验选区、读取上下文并沿用现有计费；不提供工具、不修改正文。章节检查改为清楚的中文说明、缺计划/加载/失败状态分开。草稿已有版本替换机制保留。
**Tech Stack:** React/shadcn/Lucide/现有ModelClient，Node24.22.1，无新依赖。
**Execution:** 当前会话执行，不派生代理。
