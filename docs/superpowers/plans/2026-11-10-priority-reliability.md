# 当前优化顺序

范围：本地个人创作工作台。保留作者确认、候选与正式正文隔离；不调用真实模型，不改变作品内容或提交本地密钥。

1. **P1 正确性：辅助状态故障隔离。** 结构提取进度文件损坏时，全部提示仍可读，计划保存如实返回成功；覆盖情况明确标为未知，原文件保留。以损坏文件与保存计划回归验证。
2. **P1 正确性：原文定位。** 结构图、告警、完成依据和检索链接保留引文出现次数及偏移；重复引文不再跳到第一处。旧链接保持可用，非法参数安全降级。
3. **P2 性能：长篇状态读取。** 单次读取按章分组事件，减少每一章重复扫描全书。比较合成作品优化前后的耗时和扫描次数，验证确认操作后立即显示新状态。
4. **P2 交付：跨平台检查。** 保留现有 Linux 浏览器检查，补 Windows/macOS 的安装、类型、单测、构建检查；公开文档记录本地证据与尚未在远端运行的部分。

验证：先证明故障，再实施并运行对应回归，最后进行完整类型检查、单测、构建及本地服务冒烟检查。当前浏览器控制未开启，浏览器交互与真实模型质量不能由单测结果代替。

后续队列：结构重复/身份歧义的来源合并体验、合成文学质量评测、新手教程；许可证与多人平台方向需要产品决策，真机测试单列。
