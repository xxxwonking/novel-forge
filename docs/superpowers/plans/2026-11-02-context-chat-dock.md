# 可收起 AI 侧栏实施计划

**Goal:** 在作品资料、章节/草稿、返修和剧情视图并排使用现有 AI 对话，保留独立对话页。
**Architecture:** 借鉴旧 ChatDock 的应用级生命周期，不合并旧分支。ProjectApp 只挂载一个 Chat；Chat 内部复用当前会话、流式请求、重试及确认流程，ChatSurface 按桌面并排/窄屏 Sheet/独立页切换呈现。隐藏仅卸载视图，不卸载会话状态。宽度本机保存、作品状态不受影响。
**Tech Stack:** 现有 React 19、shadcn/Radix Sheet、Lucide、CSS、Playwright；无新增依赖。Node 24.22.1。
**Execution:** 按用户既有要求在当前会话执行，不派生代理。

## 设计边界
沿用 DESIGN.md 中性色及双主题。默认收起，按钮显式打开。桌面 >=1200px 可拖动分隔线，键盘左右箭头/Home/End 调宽；保证主区宽度。较窄窗口/手机用右侧模态抽屉，关闭与 Escape 恢复焦点，不挤压主区。对话功能保持完整，侧栏采用紧凑工具栏。
