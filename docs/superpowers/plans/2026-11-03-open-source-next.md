## P0：先把编辑闭环做完整（本批完成）

- [x] 在章节旁把AI替代建议转为可编辑候选，显示原文/新文差异；保持问答和替代文本的区分，不能把解释性回复整段当正文覆盖。
- [x] 用户确认后仅替换精确选区，保存新稿版本，复用现有编辑/检查/采用流程；不直接覆盖正式正文。
- [x] 重复段落、原文已变化、跨段选择、截断回复分别处理；来源版本冲突时停止应用，保留用户输入。
- [x] 撤销应用或返回旧版本，显示保存状态；补正文编辑缓冲的自动保存与崩溃/刷新恢复。
- [x] 验收：选段→AI候选→差异核对→保存新版本→检查/采用→撤回；原文哈希、版本冲突与恢复都有证据。

现有版本编辑和草稿历史是基础，本批应把它们接到段落助手，不另建第二套版本系统。

验收与范围说明见 [选段编辑闭环记录](../../reports/2026-11-03-passage-editing.md)。候选是临时预览，自动恢复覆盖正文版本编辑器；真机和真实模型文学质量不包含在本批通过项。

## P0：结构记录复核与体检可信度

- [ ] 统一呈现各章结构提取覆盖、来源引用、待确认/已确认/过时状态；把现有反推、纠正和体检入口串起来。
- [ ] 对重复伏笔、存疑兑现、身份歧义提供有来源的合并/纠正建议及影响预览，保持作者确认。
- [ ] 区分正文真的未兑现、结构未更新、未提取三个原因；根据严重度与来源组织提示，避免几十上百条警告淹没作者。
- [ ] 验收：以已知有缺口的副本逐项核对，不通过自动关闭伏笔或批量确认来清空告警。当前雨夜175章的143条跨章提示只是记录状态，不是143个经语义确认的正文错误。
