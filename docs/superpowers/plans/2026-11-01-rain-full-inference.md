# 《雨夜当铺》全书结构验收计划

**Goal:** 在隔离副本完成175章逐章结构反推的程序验收，核对出处、覆盖与视图，记录不能自动证明的语义问题。

**Architecture:** 复用`src/import/inference.ts`的顺序反推/确认，不另建产品后门。原始小说和已验收作品只读，复制后记录正文哈希。隔离副本的确认仅供跨章累计测试，不回写作者正式作品，也不冒充作者文学核对。

## Chunk 1：准备与小范围

- [x] 复制已整理人物/情节线的175章项目到本次独立验收库；记录原副本文件哈希、175章正文摘要及旧账本基线。
- [x] 检查人物、主支线、完结状态、反推状态和费用预估；已有4个资料节点继续标为资料推断，不将其当逐章事实。
- [x] 先跑前10章。每章程序核对通过后仅在隔离副本确认，验证跨章ID、原文锚点与视图投影。输出每次调用记录与费用。

## Chunk 2：全书与故障定位

- [x] 分批顺序完成后续章节，不并行跳章。网络/认证/超时即停止并保留现场；内容/格式/出处失败先定位，不暗中自动跳过。
- [x] 对实际缺陷先补失败测试再修复；模型随机失败与程序缺陷区分，重跑需明确记录，不隐式无限重试。
- [x] 如需作者语义决定则保留问题及候选，不把未核对内容称为正式正确；不为凑175而伪造事件或确认失败结果。

## Chunk 3：验收与交付

第127章两次重复埋设已知伏笔，现有产品只能重跑/整章跳过。新增本批必要的人工复核路径：

- [x] `infer.ts`仅在原输出只有重复埋设问题、剩余有效声明的引用检查全部通过时保存有效候选；问题项不静默删除，不放宽原确认入口。
- [x] `inference-store.ts`保存候选和来源指纹；`inference.ts`新增带版本令牌的显式复核确认，重读当前人物/伏笔/正文并再次校验；来源变化、伪造令牌和引用失败拒绝。排除原因留档。
- [x] `api.ts`与`Inference.tsx`提供复核弹窗，展示排除原因和保留记录；此能力不给模型工具，只有明确的作者动作触发。
- [x] 先失败后修复覆盖重启、来源变化、伪造令牌、引用错误和重复提交；浏览器验收手机弹窗/取消/确认。只在隔离副本人工核对后使用，不回写原作品。

- [x] 核对175章状态分布、情节线覆盖、人物弧线、伏笔、所有有效锚点逐字定位、资料出处与重复认领；抽查开端/中段/终章语义。
- [x] 比较原目录文件哈希与副本175章正文；0章正文改写/采用，报告覆盖数、失败数、实际调用/积分和剩余问题。
- [x] 浏览器检查密集白板/情节线/人物/伏笔、手机与桌面；提交报告并更新总路线状态，真实文学质量结论单列。

## 结果与接续

程序验收已完成；结果与限制见 `docs/reports/2026-11-01-rain-full-inference.md`。175章被隔离副本程序确认，不代表作者认可全部语义。134章有独立剧情事件，41章没有；只使用既有15名人物、1条主线，人物/支线覆盖未完成。第127/137/154章经过显式人工复核，第154章撤掉错误完整兑现，仅保留出场。
