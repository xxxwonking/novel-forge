# novel-forge 项目检查与首版创作流程完成计划

> **执行方式：** 当前代理按 `superpowers:executing-plans` 分段实现、测试、自审。用户明确禁止独立 Agent，不进行委派。本文是持续任务清单，完成其中一段不等于项目完成。

**Goal:** 先检查当前小说项目的问题，再完成已约定的首版使用流程：从想法创建作品、准备资料、对话写章、查看与修改结果、逐章采用、续写、返回恢复和基础正文导出。

**Architecture:** 沿用 TypeScript、LangGraph 章节任务、原生模型客户端和现有 React 工作区。正式故事事实仍由事件流维护；作品资料、候选方案、运行状态和稿件历史分别保存，按钮与对话调用同一业务入口。多作品选择按每个请求指定作品，避免一个页面切换影响另一个页面的运行任务。

**Tech Stack:** Node.js 24、TypeScript 5.9、LangGraph JS、React 19、Vite 6、Vitest 3；浏览器用本地 Chromium + Playwright 验证。
