# 按优先级优化：本轮结果

本轮先处理来源定位与状态可信度，再优化长篇读取，最后补交付检查。没有调用真实模型、改变小说内容、提交或推送代码。

## 已完成

| 优先级 | 问题 | 结果与验证 |
| --- | --- | --- |
| P1 | 结构提取进度文件损坏会使全部提示无法读取 | 仅降级覆盖信息，明确显示未知；提示及原文依据仍可查看，不把未知标成零章或完成。损坏文件保留。故障注入测试覆盖读取与后续计划保存。 |
| P1 | 结构图、告警、完成依据及检索丢失重复引文的定位信息 | 跳转统一保留出现序号与偏移。检索返回对应序号，正文页将完整参数交给原定位服务；旧链接兼容。重复引文、特殊字符及非法参数测试通过。仅有引文、没有具体位置的旧来源仍沿用原行为。 |
| P1 | 结构图圆点只能鼠标点击 | 有效出处支持键盘聚焦、Enter/空格操作，并提供名称及焦点样式；失效出处继续不可操作。事件测试与渲染检查通过，未做真实浏览器预览。 |
| P2 | 每章状态读取重复遍历全书事件 | 单次请求先按章分组；不跨请求缓存，确认后立即可见新状态。300 章回归验证一次枚举及确认后的状态变化。 |
| P2 | 自动检查仅覆盖 Linux | 增加 Windows/macOS 的安装、类型、单测、构建任务，保留 Linux 浏览器回归。配置解析通过，尚未提交到远端执行。 |

计划保存原来就有独立响应，损坏的提取进度不会使保存本身失败。本轮测试保留这一边界，修复的是后续读取全部提示时的故障。

## 性能证据

同一台 Windows 主机，Node 24.22.1；合成数据为 1,000 章、30,000 条已有正式记录，每章 1,000 个正文字符。内存来源、预热一次后测量五次完整状态读取；均不调用模型。

| 指标 | 修改前 | 修改后 |
| --- | --- | --- |
| 每次普通状态读取的事件源调用次数 | 1,000 | 1 |
| 五次耗时中位数 | 148.39 ms | 15.53 ms |
| 五次样本 | 138.78 / 139.68 / 155.89 / 181.51 / 148.39 ms | 15.53 / 20.87 / 15.52 / 15.68 / 14.62 ms |

这一测量针对结构状态读取，不包含磁盘、浏览器绘制、待纠正候选的语义复核，也不代表整页或真实模型的速度。

## 验证

- 完整类型检查、前端构建通过。
- 最终完整测试：115 个测试文件、1,632 项通过。
- 首轮同时运行构建与全量测试时，已有的检索性能比值测试为 26.60，超过原阈值 25；单项复测通过，构建结束后的完整测试也通过。未调宽阈值。
- 新增浏览器回归检查重复引文链接；当前本地浏览器控制未开启，该浏览器场景未执行。
- 布局静态检查没有发现问题；不代替浏览器、触屏或真实设备验证。
- 服务已重启，首页及当前静态入口、作品资料、全部提示、结构进度接口返回 200。
- 检查可进入 Git 的文件及暂存内容，未找到当前本地配置中的密钥；密钥配置继续被忽略。

## 后续优先级

1. 完善重复伏笔、存疑兑现、身份歧义的来源对照及合并建议；只生成候选与影响预览。
2. 首次使用流程串联模型配置、资料准备和首次候选，不自动消耗模型额度。
3. 建立可公开的合成文学质量评测，分别记录重复、人物声音与事实连续性；真实模型验收与程序测试分开。
4. 浏览器控制可用后补交互验收；物理设备触控与软键盘另行验证。

项目许可证与多人部署方向继续保留为产品决策。
