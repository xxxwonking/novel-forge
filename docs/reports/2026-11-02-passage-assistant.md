# 正文选段与段落助手验收

## 交付

- 正式正文、草稿已生成片段可直接选择，浮动入口提供问 AI / 润色 / 改写。按 DOM 对应的原文偏移传输，重复句子、跨段及高亮不靠全文首次匹配。
- 原体检栏默认变为段落助手，另有章节检查标签解释计划、字数、事件密度与跨章规则检查。无计划章仍可讨论；检查网络失败不显示成缺计划。
- 独立只读服务验证原文及草稿版本；附前后各1600字符、有限讨论历史，使用当前创作模型及既有计量。不提供 Agent 工具，不修改稿件。失败可重试，截断/过时来源显式标记，建议可复制。
- 右上角通用助手保留。辅助区按可用宽度排为左右/上下布局，避免同时打开通用助手时正文过窄。无新依赖。
