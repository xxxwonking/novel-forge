# 剧情白板首版验收

## 交付范围

- 新入口 `#/plotboard`，保留 `#/plotlines` 章节轨道。
- shadcn 风格的局部中性色界面；现有 React / Ant Design 页面保持原体系。按钮和布局使用语义 HTML 与局部 CSS，没有声称迁移整站到 shadcn/ui。
- React Flow 负责无限画布平移、缩放、拖动和键盘移动；支持适配全部、定位选中、主支线/章节收起与展开、搜索摘要/人物/章号、完整详情与有效原文跳转。
- 已确认事件与未来已确认章计划分开显示；候选/拒绝记录不进入白板。未分线事件保留，且不会被自动连成同一情节线。连线仅表示同线时序。
- 事件用稳定事件 ID；计划内容版本进入 ID。布局按浏览器 origin 和作品 ID 隔离，刷新后恢复，换版/删除节点的坐标在加载时清理。
- 章节数不预设，不设 100 章上限。最小缩放根据实际布局范围派生，避免固定缩放间接限制长篇的“适配全部”。
- 白板代码与 CSS 按路由独立加载。本次构建白板 JS 199.60 kB（gzip 65.39 kB），主入口 JS 974.68 kB；已有主包大于 500 kB 的构建提醒仍在。

## 验收证据

| 场景 | 结果与边界 |
| --- | --- |
| 现有真实导入作品的独立副本 | 100 章样本、248 个确认事件，其中 15 个未分线；主支线、人物、摘要与原文详情可读。100 是该样本大小，不是限制。原作品与测试副本原有文件逐一比较无差异。 |
| 作者桌面《雨夜当铺》 | 实际 175 章，导入计量 528,739 字，另收下角色档案和目录简介。只在独立测试项目中导入；177 份输入文件（175 章+2 份资料）的 SHA-256 复核无变化。 |
| 《雨夜当铺》白板验证 | 中转不可用，使用第 1、2、87、175 章的 4 条**节选验收标注**，卡片与分组明确写明验收用途。4 个锚点均 exact；网页点击第 175 章节点后打开正文并逐字高亮。不是全书结构反推结果。 |
| 稀疏章号和未来计划 | 合成作品只有第 1、1500 章正文与第 5000 章计划；没有补造中间空章节。计划虚线、来源“章计划”、没有正文入口。第 1500 章失效引用显示降级提示。 |
| 密集长篇 | 纯布局测试使用 5000 个连续章节点，最小缩放随范围变小；不是 5000 章真实模型或浏览器性能验收。 |
| 画布交互 | 鼠标拖空白后视口平移 (100,60)；鼠标拖卡片后坐标变化。方向键移动事件卡 x:29328→29333；Escape 关闭选中详情。刷新后 x:29333 与视口 transform 均保持。 |
| 分组与定位 | 全部收起为紧凑总览；单线、单章可收起。搜索第 100 章从收起状态展开并选中真实事件。搜索选择曾触发循环，已改为由画布节点唯一持有选择状态，同路径与键盘复验通过。 |
| 作品隔离 | 从真实作品切到合成作品，视口从真实作品的远端平移恢复为新作品初始视口，折叠状态不继承；切回后真实作品保存位置仍在。 |
| 响应式 | 1440×1000 桌面与 390×844 窄屏；窄屏目录按需展开，搜索定位后收起；详情在画布下方，可由键盘访问。页面宽度/scrollWidth 都为 390，无页面横向溢出。 |
| 空态与失败 | 空作品提供作品资料和旧稿补全入口。临时关闭测试 API 后刷新显示读取失败和重新加载入口；恢复服务后画布可重新打开。 |
| 生产构建 | 通过独立静态构建入口加载白板并展开/适配；新浏览器标签的控制台 warn/error 为空。 |

## Gemini 测试边界

用户授权使用《雨夜当铺》和正常 Gemini 消耗。真实调用人物起草两次，均在连接阶段 `fetch failed`（约 3.3/3.4 秒）；独立 curl 探测得到 Empty reply from server。没有取得可确认的模型结构、没有伪造全书反推通过，也没有把失败的章节批量标为作者跳过。账本没有可计量的成功调用（不是供应商账单判断）。用户随后明确选择“暂未恢复，先完成白板交付”，因此停止重试。

中转恢复后可单独复验人物/情节线资料起草及逐章反推。当前测试副本有明确标记的人工节选标注；复验全书模型链路应从干净独立项目开始，避免把验收标注当成正式结构。

## 工程与界面复核

- 全量：85 文件，**1407 passed / 1 skipped**；类型检查（根与 web）、生产构建、`git diff --check` 通过。
- 读模型与布局/来源定向测试先观察失败再实现；API 测试确认 GET 不改事件和章计划。
- Impeccable 机械检测结果 `[]`。按用户约定由当前代理独立自审，没有子代理。
- 自审 disposition: **ship**，限首版只读剧情与当前浏览器布局。画布/详情/原文跳转、状态区分、收起与重置、窄屏与焦点符合本次约定；截图可核对。没有将模型反推、规划编辑、跨设备保存纳入通过范围。
- 界面文档核对源：`web/src/styles.css` 的既有深色外壳与字体，`web/src/pages/plot-board.css` 的局部 zinc tokens、字号、边框与断点。保留既有系统；没有趁局部白板工作重写整站设计规范。方向记录在实现计划。

## 已知限制

布局保存在当前浏览器；换浏览器/换设备或清理站点数据不会自动恢复。本版只浏览剧情，拖动不修改正文/章计划，不支持直接连线或编辑未来剧情。大范围适配后应放大、按目录或搜索深入节点；超大作品的浏览器性能仍需单独实测。

技术依据：[React Flow 官方文档](https://reactflow.dev/learn)、[shadcn/ui 主题文档](https://ui.shadcn.com/docs/theming)。新增依赖 `@xyflow/react` 12.12.0，MIT，声明支持 React >=17；本地 React 19。本地 Node v24.20.0 位于 [官方仍支持的 v24 LTS 系列](https://nodejs.org/en/about/previous-releases)，未更换运行时，也没有把“LTS”当作补丁安全审计结论。
