# 选段编辑闭环交付记录

范围：本地单用户创作。用户已确认许可证、多人在线继续待定，真机验收延后。

## 已实现

- 段落助手保留问答，另有“生成替代候选”。模型须分别交付替代正文和解释；格式错误、截断、来源已变化时不能生成可应用候选。
- 候选可编辑、查看修改前文字。确认只替换精确选区，保存为待检查新版本，随后进入既有检查/采用流程。正式原文不会随生成或保存改变。
- 导入的无计划章节也能保存、检查和采用。检查明确跳过计划兑现、预算与密度；不伪造章节计划。旧章返修继续记录下游影响。
- 首次修改导入正文时保留原文版本；修改前后面板可将旧正文恢复为另一份新稿，仍需检查并采用。
- 正文编辑缓冲按作品/章/稿件保存到本浏览器。刷新后由作者选择恢复；来源凭据不刷新替换，冲突保留输入。保存成功清理缓冲，配额或存储故障如实提示。
- 完整原文指纹、草稿版本凭据、请求编号共同防止错替重复段落、覆盖并发修改及重试重复建稿。

## 边界与后续

本批验证程序行为，没有用真实供应商评判文学质量，也没有执行iPhone真机验收。候选编辑区是临时预览；自动恢复覆盖“修改正文”的编辑缓冲，浏览器清理站点数据会删除缓冲，已保存的版本稿仍在作品目录内。

下一批为结构记录复核与体检可信度；开源发布材料、跨平台CI和文学评测仍在总路线图中，不随本批标记完成。
