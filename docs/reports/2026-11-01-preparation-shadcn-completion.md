# 作品资料缺陷修复与全站 shadcn/ui 迁移交付

用户授权修复上一轮验收的缺陷，完成整体 UI 替换，自审后提交、推送并合并。当前代理独立实现与自审，没有派生代理。工作分支 `codex/preparation-shadcn-completion`，从 `21aef79`（含上一轮验收记录）准备，目标 `origin/master` 基线 `6cbb7e4`。

## 缺陷与结果

| 缺陷 | 修复与证据 |
| --- | --- |
| 整份资料起草没读导入材料、另造主角 | full 读取导入材料与六章章首抽样，并补最近正式章结尾；按实际下一章接续，完结书不自建续章。已有非空作者设定与写作规则不得被“补齐”覆盖，失败回喂模型修正。独立 `rain-full-final` 真 Gemini 返回许临川、顾以南等7人、4地点及主线，无历史影响阻断，已确认。 |
| Map 顺序改变导致未变候选过期 | 指纹按章号排序，兼容当前资料的旧字典序指纹；实际修改仍过期。12章导入→候选→重开→确认及旧版本候选回归通过。 |
| 初次补空字段也拦住175章 | 区分首次补录与改写已有非空设定；补录仍保存方案并由作者确认，已有设定变更仍要求处理正文。真实导入后核心冲突/开篇补录成功。 |
| 人物档案导入后不显示生成方案 | AI成功后重新读取资料，候选立即可见；真实网页导入后11人/24关系方案立即出现，确认后持久化。 |
| 第二卷覆盖第一卷 | 新卷号同时参考卷卡和章计划；无章计划时也能连续建立卷1、卷2。 |
| 已排176仍新增176 | 新增计划取实际下一正文章与已有最大计划号的下一号，编辑保留原编号；176保存后新增弹窗显示177。 |

排章缺正式人物或地点时，在模型调用前说明缺项，回归验证0次调用。人物关系候选以候选内人物解析姓名，避免新建人物显示裸ID。

补做情节线网页验收出现连续两次轮数耗尽。独立调用轨迹表明模型反复漏根级 `summary`，并尝试把它塞进 `volume`。工具 schema 原本正确，程序也没有接收错误提案。增加根对象示例和具体错误反馈，失败回归再转绿；新服务网页重跑成功保存并确认 `P_Investigation`，没有自动采用正文。失败时弹窗保留补充要求，可显式重试；没有增加自动重试。

## 全站组件与样式

- 官方 Radix/new-york-v4 shadcn 源码：补齐 Dialog、AlertDialog、Input、Textarea、Select、Checkbox、Switch、Tooltip、Popover、Toggle/ToggleGroup、Collapsible、Alert；原 Button/Badge/Sheet/Separator 继续使用。来源、原始registry哈希和许可证保留。
- `controls.tsx` 仅组合这些真实 primitives：异步/禁用按钮、空值数字输入、单选及可搜索多选、确认弹层、滚动正文和焦点归还。未在内部调用 Ant Design。
- 剩余25个直接引用 Ant Design 的 TSX 文件全部替换，删除入口 provider、theme、旧覆盖样式及3项直接依赖。源码与安装树检查无生产 Ant Design。
- 页面标题、导航与控件统一 sans / zinc；正文独立衬线排版、图表主支线与状态文字保留。CSS顺序统一 theme→layout→base→components→utilities，避免原全局样式压住真实控件。
- 聊天输入最小124px，仅输入框聚焦高亮；阅读器底部保留可达。长弹窗固定头/底部操作，正文独立滚动，窄屏编辑器保存按钮完整可见。显式 rows 的文本区固定行数（2628字符原稿编辑区高218px、内部滚动1876px）；交互按钮 Tooltip 不额外制造一个 tab 停点，非交互状态说明仍可键盘访问。
- 自审追加修正：草稿建议标题与勾选统一在一个 label 中，避免嵌套label；阅读进度条保留对比色；清空检索与重复原文位置选择均保留显式入口；长方案卡片明确以Tailwind覆盖按钮的固定高度/单行默认，桌面225px宽自动增高，窄屏无溢出。

## 真实生成边界

一次自动修订仍为上限，字数下限仍2700。新增单次响应1–4处补写协议，所有位置先校验再应用，保留冻结原稿，非法位置、重复位置/内容及整章重复整份拒绝；旧单位置/偏移任务恢复保留。新稿仍重新核对结构并过同样闸门。

| 副本 | 初稿→一次补写 | 结果 |
| --- | --- | --- |
| rain-writing-fixed-a | 1250→2332字 | needs_revision，低于2700，0章采用 |
| rain-writing-fixed-b | 897→2886字 | ready/acceptable，UI明确采用176章，仍有密度与说话方式警告 |

**改善不等于稳定**：没有证明两章连续自动采用，也没有证明文学质量定稿。资料只读全文材料+抽样/末章，未做175章逐章反推。原始177份输入及所有雨夜副本原有175章哈希相同；只有明确采用的独立副本b新增176章。AI关系/推断仍由作者核对，不能声称全对。
