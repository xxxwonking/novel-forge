# 有界分场生成与真实连写验收

基线：master `6b62b61`（已按用户要求合并PR #38）。本批在`codex/stable-generation`独立工作树实施，沿用现有LangGraph、ModelClient和草稿，不新增依赖。

## 实现

- 新任务可选择分场方式，每章按原预算拆为2–6场，场景覆盖原计划事件；同一事件可以分阶段推进，不能因多个场景引用同一原事件就误判重复。最终正文仍使用同一C5、代码检查、声音/语义审查和采用门槛。
- 拆场与已完成正文存同一草稿检查点。暂停、重启和C5失败恢复跳过已完成步骤；失败/截断保留片段，损坏检查点拒绝续写。来源指纹变化继续阻止使用旧依据。
- 每章冻结总调用次数和积分停止线，覆盖拆场、正文、工具、声明、审查及最多一次自动修订；自动修订与恢复继承统计，配置对象异步修改不能提高额度。已计价消耗达到停止线后不再发请求，在途调用可能越线。
- 未知用量/未计价调用不当免费；作者明确核对后可继续剩余任务，原未知统计不删除，次数不重置。连写即使在最后一次声明才出现未知计价也不静默自动采用。
- 资料页、章节结果页、连写弹窗与任务卡复用shadcn控件。对话工具支持作者明确选择的分场配置，非法配置不能降级成无预算的旧方式；未选择的新API请求及旧任务兼容原协议。
