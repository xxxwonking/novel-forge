## 发现并修复

1. 手机宽度被 Sheet 默认 w-3/4 工具类覆盖（实测292.5px/390px）。在组件调用处显式覆盖宽度/高度/gap；断言先失败再通过。
2. 隐藏重建视图后长回复阅读位置归零。Chat保存滚动位置，呈现后恢复；断言先失败再通过。
3. 嵌套历史刚挂载时 Radix 层级注册尚未完成，Escape偶尔误关外层（重复执行复现两次，日志显示外层在2个dialog时处理Escape）。外层显式优先关闭内层，共用焦点恢复允许回到下层弹窗，连续三轮通过。
4. 浅色axe曾赶在主题菜单退场动画完成前执行；改为等待listbox卸载，再检查稳定页面，没有屏蔽规则。
